Pesquisas sobre Automação Industrial

Sistemas Supervisórios, MQTT, Alarmes, ISA-101, Modos de Operação e UX

Pesquisa 1 – Arquitetura Supervisória

O que é um sistema supervisório?

Um sistema supervisório, também chamado de SCADA (Supervisory Control and Data Acquisition), é um software utilizado para monitorar, controlar e adquirir dados de processos industriais em tempo real. Ele coleta informações de sensores, CLPs e máquinas industriais.

Qual a função de um servidor de dados?

O servidor de dados é responsável por receber, armazenar, processar e distribuir as informações coletadas dos equipamentos industriais para os demais componentes do sistema supervisório.

O que são clientes (viewers)?

Clientes ou viewers são interfaces utilizadas pelos usuários para visualizar dados em tempo real, gráficos, alarmes e telas do processo industrial.

Pesquisa 2 – MQTT

O que é MQTT?

MQTT (Message Queuing Telemetry Transport) é um protocolo de comunicação leve utilizado em IoT e automação industrial para troca de mensagens entre dispositivos.

O que é broker?

O broker é o servidor responsável por gerenciar toda a comunicação no MQTT, recebendo e distribuindo mensagens.

O que são tópicos?

Tópicos são canais de comunicação utilizados para organizar as mensagens no MQTT.

Diferença entre publisher e subscriber

Publisher Subscriber
Publica ou envia mensagens Recebe mensagens
Envia dados ao broker Se inscreve nos tópicos

Pesquisa 3 – Alarmes Industriais

O que são alarmes em sistemas industriais?

Alarmes industriais são mecanismos utilizados para alertar operadores sobre situações anormais ou perigosas em processos industriais.

Importância de alarmes bem configurados

  • Maior segurança operacional;
  • Redução de falhas e acidentes;
  • Melhor tomada de decisão;
  • Evita excesso de alarmes desnecessários.

Pesquisa 4 – Norma ISA-101

O que é a norma ISA-101?

A norma ISA-101 define boas práticas para o desenvolvimento de IHMs utilizadas em sistemas industriais, buscando melhorar clareza, segurança e eficiência.

O que é IHM de alta performance?

Uma IHM de alta performance é uma interface projetada para facilitar a identificação rápida de problemas, utilizando layout simples e organizado.

  • Uso reduzido de cores;
  • Destaque para alarmes importantes;
  • Melhor leitura das informações;
  • Maior eficiência operacional.

Pesquisa 5 – Modos de Operação

Diferença entre modo manual e automático

Modo Manual Modo Automático
Controle feito pelo operador Controle feito pelo sistema
Mais utilizado em manutenção Mais utilizado na produção
Maior possibilidade de erro humano Maior precisão e produtividade

Pesquisa 6 – UX em Sistemas Industriais

O que é UX?

UX (User Experience) significa experiência do usuário e representa como uma pessoa interage com um sistema de forma simples, intuitiva e eficiente.

Por que é importante em supervisórios?

  • Facilita a visualização das informações;
  • Reduz erros humanos;
  • Melhora a identificação de falhas;
  • Aumenta a segurança e produtividade.
